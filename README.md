*Full stack developer who started in data, then took a way through web also mobile, and never quite left the "wait, how does this actually work?" phase.*

## The story so far
 
It started with Python and a pile of datasets on Kaggle. I worked my way through the deep learning courses, mostly because I wanted to know how a machine could learn something from nothing but examples.
 
But a model on its own doesn't do much until someone builds the thing people actually use. Destiny pulled me toward the web: **CodeIgniter 3 and MySQL** were my first backend, humble tools that taught me the fundamentals better than any tutorial.
 
Then I wanted my work to live in people's pockets, using **Flutter**. Later I came back to the web with **Next.js**, and I fell in love with how much a good frontend and backend can feel like one system.
 
Once, I just wanted to build a simple website as fast as possible. I asked AI for advice, and it told me to use **Rails**. That turned out to be a great call. Along the way I also picked up **Go** and **Jetpack Compose**, just to see how other ecosystems think.
 
These days I spend my free time on side projects with **Next.js, NestJS, Elixir, Redis and PostgreSQL**, where the fun questions live: caching, concurrency, real-time behavior, and what happens when many things go wrong at once.
 
I'm not a specialist in one stack. I'm a person who likes to follow a problem wherever it leads.

## How I like to build

- **Understand before you copy.** A snippet I don't understand is a bug I haven't met yet.
- **Make it work, make it right, make it fast.** In that order.
- **Boring tech, interesting problems.** Pick tools that stay out of the way.
- **Ship small, learn loudly.** Small releases teach more than big plans.
- **Stay curious.** Every stack I've learned started as "I wonder how that works."
